A statically configured, time-partitioned RTOS for ARM Cortex-M7. Partitions get fixed time slots and MPU-enforced memory domains, with queuing-port IPC and a health monitor that restarts or halts faulty partitions. The whole system is described in one JSON file that a code generator turns into C and a linker script.
